# Orbis Estudio vs TradingView — tabla comparativa honesta

"Sí en básicas": el Estudio cubre el flujo básico de análisis PAPER; no pretende
clonar TradingView.

| Capacidad básica | TradingView | Orbis Estudio |
|---|---|---|
| Velas + línea + área + barras | Sí | Sí |
| Temporalidades 1m-1w | Sí | Sí (nativas por exchange) |
| Zoom rueda/táctil + pan | Sí | Sí |
| Crosshair OHLC + fecha | Sí | Sí |
| Volumen en pane propio | Sí | Sí |
| SMA / EMA / Bollinger / RSI / MACD | Sí | Sí (parámetros + persistencia) |
| Línea horizontal / tendencia / vertical / zona / texto | Sí | Sí |
| Medidor precio + % + tiempo | Sí | Sí |
| Long/Short con riesgo y ratio R | Sí | Sí (solo matemático, sin consejo) |
| Fib retracement + extensión | Sí | Sí (0-1 + ext. 3pts, niveles custom) |
| Alertas de precio | Sí (servidor) | Sí (local, sesión + persistidas) |
| Comparar símbolos (% normalizada) | Sí | Sí |
| Watchlist | Sí | Sí (persistente) |
| Múltiples exchanges en un clic | Parcial | Sí (10 + AUTO visible) |
| paper-trading integrado con Ledger | No | Sí (PAPER, Guard,_DCA, provenance) |
| Tiempo real multi-fuente institucional | Sí | No (GRVT sólo consulta puntual; streaming pendiente) |
| Indicadores Pine / comunidad | Sí | No (fuera de alcance v1) |
| App móvil nativa | Sí | No (web responsive dark es-ES) |
